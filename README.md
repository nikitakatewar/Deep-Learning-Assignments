# Deep Learning Assignments

This repository contains the practical implementations performed as part of the **Deep Learning Laboratory**.

## Assignments

### Assignment 1 – TensorFlow/Keras and Data Preprocessing

- Installation and configuration of TensorFlow/Keras in Google Colab
- Data preprocessing and normalization
- Dataset visualization
- Train-test split
- Fashion MNIST classification using a Sequential neural network

### Assignment 2 – Multilayer Perceptron (MLP)

- Implementation of Multilayer Perceptron
- Iris dataset classification
- Feature standardization using StandardScaler
- Comparison of different MLP architectures
- Evaluation using accuracy, precision, recall, F1-score, and confusion matrix

### Assignment 3 – Forward Propagation and Backpropagation

- Implementation of forward propagation and backpropagation
- Iris dataset classification using TensorFlow/Keras
- Analysis of different learning rates
- Analysis of different numbers of epochs
- Comparison of model performance

### Assignment 6 – Convolutional Neural Network (CNN)

- Implementation of CNN for image classification
- Tomato disease image classification
- Image resizing and normalization
- Convolution and pooling layers
- Evaluation using accuracy, loss, confusion matrix, precision, recall, and F1-score

### Assignment 7 – Transfer Learning

- Implementation of transfer learning
- CIFAR-10 image classification
- Transfer learning using pre-trained VGG16
- Transfer learning using pre-trained ResNet50
- Comparison of model performance
